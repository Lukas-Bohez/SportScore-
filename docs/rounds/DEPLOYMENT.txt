API ENDPOINTS (6 new)
====================
POST /api/v1/activities/{id}/rounds/start       → Starts round, begins timer
POST /api/v1/activities/{id}/rounds/end         → Ends current round
POST /api/v1/activities/{id}/rounds/pause       → Pauses active round
POST /api/v1/activities/{id}/rounds/resume      → Resumes paused round
POST /api/v1/activities/{id}/rounds/next        → Advances to next round
GET  /api/v1/activities/{id}/rounds/status      → Returns round status & time

TROUBLESHOOTING
===============
Timer not showing:
  → Check: total_rounds > 1 OR time_limit_per_round set
  → Check: HTML has round-info and timer elements
  → Check: Browser console for errors

Auto-advance not working:
  → Check: round_timer_monitor task running in logs
  → Check: round_status = 'active'
  → Check: time_limit_per_round is set to number > 0
  → Check: round_start_time is not NULL

Socket events not received:
  → Check: WebSocket connection active
  → Check: Browser console for connection status
  → Check: Firewall not blocking /socket.io path

Syntax errors:
  → Python: python -m py_compile backend/app.py
  → JavaScript: node -c backend/.../js/*.js
