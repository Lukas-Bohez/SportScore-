Herstelgids

1 Inleiding

Deze gids helpt je bij het herstellen van SportScore als de Raspberry Pi of SD-kaart beschadigd is. Zorg ervoor dat je een backup hebt van belangrijke gegevens voordat je begint.

GitHub Repository: https://github.com/Lukas-Bohez/SportScore-

2 Benodigdheden

  • Een nieuwe of lege SD-kaart (minimaal 16GB, Class 10).
  • Raspberry Pi Imager software (download van raspberrypi.com).
  • Een computer met SD-kaartlezer.
  • Internetverbinding voor downloads.

3 SD-Kaart Flasheren

  1. Raspberry Pi Imager Downloaden: Download en installeer Raspberry Pi Imager van raspberrypi.com/software.
  2. OS Selecteren: Kies "Raspberry Pi OS (other)" > "Raspberry Pi OS Lite (64-bit)". Selecteer je SD-kaart en klik op "Write". Wacht tot het flashen klaar is.
  3. SSH Inschakelen: Na flashen, plaats de SD-kaart in je computer. In de boot-partitie, maak een leeg bestand genaamd 'ssh' (geen extensie).
  4. WiFi Configureren: Maak een bestand 'wpa_supplicant.conf' in de boot-partitie met de volgende inhoud:
country=BE
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1

network={
    ssid="jouw_wifi_ssid"
    psk="jouw_wifi_wachtwoord"
}

Vervang 'jouw_wifi_ssid' en 'jouw_wifi_wachtwoord' met je eigen WiFi-gegevens. Verwijder de SD-kaart veilig.

4 Raspberry Pi Opstarten

  1. SD-Kaart Invoegen: Plaats de geflashte SD-kaart in de Raspberry Pi en sluit stroom aan.
  2. IP-Adres Vinden: Gebruik je router of een tool zoals 'arp -a' om het IP-adres van de Pi te vinden (meestal 192.168.x.x).
  3. SSH Verbinden: Open een terminal en verbind via SSH: ssh pi@<ip-adres> (standaard wachtwoord: raspberry).
  4. Updates Uitvoeren: Voer de volgende commando's uit:
sudo apt update
sudo apt upgrade -y

5 SportScore Installeren

  1. Repository Clonen: Clone de GitHub repository:
git clone https://github.com/Lukas-Bohez/SportScore-.git
cd SportScore-
  1. Backend Installeren: Ga naar de backend map en installeer afhankelijkheden:
cd backend
pip install -r requirements.txt
  1. Database Initialiseren: Voer het database script uit:
python init_database.py
  1. Frontend Bouwen: Ga naar de frontend map en bouw de app:
cd ../frontend
npm install
npm run build

6 Hotspot en Services Configureren

  1. Hostapd en Dnsmasq Installeren: Installeer de benodigde pakketten:
sudo apt install hostapd dnsmasq -y
  1. Hostapd Configureren: Bewerk /etc/hostapd/hostapd.conf (maak aan indien nodig):
interface=wlan0
driver=nl80211
ssid=pihotspot
hw_mode=g
channel=7
wmm_enabled=0
macaddr_acl=0
auth_algs=1
ignore_broadcast_ssid=0
wpa=2
wpa_passphrase=raspberry
wpa_key_mgmt=WPA-PSK
wpa_pairwise=TKIP
rsn_pairwise=CCMP
  1. Dnsmasq Configureren: Bewerk /etc/dnsmasq.conf:
interface=wlan0
dhcp-range=10.42.0.10,10.42.0.50,255.255.255.0,24h
  1. Statisch IP: Bewerk /etc/dhcpcd.conf om een statisch IP in te stellen voor wlan0:
interface wlan0
    static ip_address=10.42.0.1/24
    nohook wpa_supplicant
  1. Services Starten: Start de services en backend:
sudo systemctl unmask hostapd
sudo systemctl enable hostapd
sudo systemctl start hostapd
sudo systemctl enable dnsmasq
sudo systemctl start dnsmasq
cd SportScore-/backend
python app.py &
cd ../frontend/dist
python -m http.server 3000 &
  1. Autostart: Gebruik de launch scripts in de repository voor automatische opstart bij boot.
Tip: Raadpleeg de README.md en scripts in de repository voor volledige configuratie. Test de hotspot door te verbinden met 'pihotspot' en ga naar http://10.42.0.1.

7 Webserver en Kiosk Modus

  1. Apache Installeren: Installeer Apache voor het dienen van de frontend:
sudo apt install apache2 -y
  1. Frontend Kopiëren: Kopieer de gebouwde frontend naar de Apache root:
sudo cp -r SportScore-/frontend/dist/* /var/www/html/
  1. Apache Configureren: Bewerk /etc/apache2/sites-available/000-default.conf om de juiste directory in te stellen indien nodig.
  2. Kiosk Modus Opzetten: Installeer Chromium en configureer kiosk modus voor het grote scherm:
sudo apt install chromium-browser -y
sudo raspi-config  # Ga naar Boot Options > Desktop/CLI > Desktop Autologin, en stel in.
  1. Autostart Kiosk: Maak een bestand ~/.config/lxsession/LXDE-pi/autostart:
@chromium-browser --kiosk --disable-restore-session-state --disable-session-crashed-bubble --disable-infobars --disable-translate --no-first-run --disable-default-apps --disable-sync --disable-background-timer-throttling --disable-renderer-backgrounding --disable-backgrounding-occluded-windows --disable-features=TranslateUI --app=http://localhost

Dit start Chromium in kiosk modus bij boot, gericht op de lokale frontend.

Tip: Zorg ervoor dat de backend draait voordat de kiosk start. Gebruik systemd timers of scripts voor sequencing.
